# ECONIER 국제송금 데모 (태국 → 한국)

투자 데모 영상 촬영용 은행원 업무화면 목업. 서버 없이 브라우저 두 창이 localStorage로 연동된다.

## 실행

```
npm install
npm run dev        # http://localhost:5173
```

## 화면

| 주소 | 화면 |
|---|---|
| `/` | 런처 (두 화면 나란히 열기, 자동 모드, 데모 초기화) |
| `/th` → `/rattana/fcubs/payments/PXOUTRMT` | 태국 Rattana Bank 당발송금 (EN / ไทย) |
| `/kr` → `/kbank/fx-ops/FXI2100` | 한국 케이뱅크 타발송금 수취 (한국어 / EN) |

두 창은 **같은 브라우저**에서 열어야 연동된다.

## 시나리오 (수동)

1. 태국: ECONIER Network 선택 → 금액 10,000 THB → 본인확인 체크 → Submit → Authorize & Send
2. 진행 모달(AML → 환전 → 서명 → 전파 → 블록 컨펌 → 장부 기록) → 완료 (~8초)
3. 한국: 알림과 함께 수취 목록에 도착 → 장부 확인됨 → [입금 확인] → 본인확인 체크 → [현금 지급] → 지급완료

## 자동 모드

창마다 따로 켠다: 상태바 오른쪽 **AUTO** 스위치, 주소 끝 `?auto`, 태국 화면은 **F9**도 가능.

- 태국 AUTO: 금액 입력 → 전송까지 혼자 진행
- 한국 AUTO: 송금이 장부에 기록되면 입금 확인 → 본인확인 → 현금 지급까지 혼자 진행
- 한국 AUTO인데 태국 창이 열려 있지 않으면, 한국 화면이 직접 송금을 받아서 진행 (한국 화면만 촬영할 때)
- 한국 화면에서 **F9**: 태국 창 없이도 송금 한 건이 바로 들어온다 (이후 버튼은 사람이 누름)

## 초기화

상태바의 "Reset demo / 데모 초기화" 또는 런처의 Reset 버튼.
